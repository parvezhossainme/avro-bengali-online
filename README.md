AvroPad
=======

AvroPad is a browser-based Avro Phonetic editor with dictionary support. It runs locally, so your typing and drafts stay in the browser.

## Setup

Install [Node.js](http://nodejs.org/) if you do not already have it, then install dependencies:

```bash
npm install
```

## Development

```bash
npm run dev
```

Open [http://localhost:8080/](http://localhost:8080/) in your browser.

## Build

```bash
npm run build
```

To build and serve the production output locally:

```bash
npm start
```

Open [http://localhost:8888/](http://localhost:8888/) in your browser.
