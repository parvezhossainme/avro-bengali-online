AvroPad
=======

AvroPad is a browser-based Avro Phonetic editor with dictionary support. The app now runs as a simple Next.js project, so it is easy to install, run, and deploy.

## Setup

Install [Node.js](http://nodejs.org/) if you do not already have it, then install dependencies:

```bash
npm install
```

## Development

```bash
npm run dev
```

Open [http://localhost:3000/](http://localhost:3000/) in your browser.

## Build

```bash
npm run build
```

To serve the production build locally:

```bash
npm start
```

Open [http://localhost:3000/](http://localhost:3000/) in your browser.
