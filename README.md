# AvroPad Next

AvroPad Next is a browser-based Avro Phonetic editor rebuilt with a modern Next.js and Tailwind stack. It keeps the writing experience focused on transliteration, with a clean full-screen editor and an IME-style candidate popup.

## Features

- Bangla transliteration powered by `nodejs-avro-phonetic`
- Full-screen editor with a modern Tailwind UI
- Live candidate popup while typing
- Keyboard-friendly BN/EN mode switching

## Setup

Install Node.js if you do not already have it, then install the project dependencies:

```bash
npm install
```

## Development

Start the local development server:

```bash
npm run dev
```

Then open http://localhost:3000/ in your browser.

## Build

Create a production build:

```bash
npm run build
```

Run the production server locally:

```bash
npm start
```
